# Fundamentum Gradnja — gotov sajt

## Objavljivanje na GitHub Pages
1. Napravi besplatan nalog na GitHub-u.
2. New repository → naziv `fundamentum-gradnja` → Public.
3. Upload files i ubaci SVE fajlove iz ovog foldera.
4. Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
5. Sačekaj nekoliko minuta i klikni Visit site.

## Važno pre objave
U `index.html` zameni:
- `+381 60 000 0000` stvarnim telefonom
- `kontakt@fundamentumgradnja.rs` stvarnim e-mailom
- po potrebi tekst „Srbija“ stvarnom lokacijom

Fotografije se nalaze u folderu `images`.
